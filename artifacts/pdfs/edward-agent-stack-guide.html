01 · What This Repo Is

Edward Agent Stack is not a private memory dump. It is a public-safe operating system for interns: stable engineering defaults, per-project context, dated decisions, and install scripts.

Edward Rules

Stable defaults for how Edward wants interns and agents to think: Codex first, source-backed, Postgres-first, no casual destructive work.

Project Notes

Current facts and priorities for one project. This is where “what matters right now” lives.

Decision Notes

Dated receipts. If Edward made a reusable decision, Codex writes it down so the same question does not come back next week.

02 · Fresh Mac Install

Paste the block below into Codex on a fresh Mac. The intern should not hand-install random tools first. Let Codex run the repo scripts, fix safe missing dependencies, and report what is blocked.

Install Edward's agent stack on this fresh MacBook. Clone https://github.com/giaphutran12/edward-agent-stack to ~/edward-agent-stack, read AGENTS.md, then run ./scripts/bootstrap-macos.sh, ./scripts/install.sh, ./scripts/verify.sh, and ./scripts/auth-doctor.sh. Use /caveman ultra for terse token-saving communication. Install prerequisites automatically when safe: Xcode Command Line Tools prompt, Homebrew, Node/npm/npx, Bun, Python/pip/uv, GitHub CLI, ripgrep, jq, tmux, ffmpeg, Supabase CLI, Vercel CLI, Claude Code, Nia CLI, Repowise, Caveman, Edward skills, and giaphutran12/codex-gstack for Codex using ./setup --host codex. Do not inspect or print real env/secret files. If a tool needs login, API key, license acceptance, or a GUI first-run step, stop and tell me exactly what is missing instead of forcing it.
  1. ./scripts/bootstrap-macos.sh: Xcode Command Line Tools, Homebrew, shell path, Rosetta when needed.
  2. ./scripts/install.sh: core CLIs, skills, Edward gstack fork, MCP template.
  3. ./scripts/verify.sh: binary/file sanity check.
  4. ./scripts/auth-doctor.sh: safe auth report without printing secrets.

04 · Auth Gates And Secrets

Installer can install binaries. It cannot create accounts, approve OAuth, accept licenses, or invent API keys.

ToolCommand / GateNote
Codexcodex loginPrimary coding agent.
GitHubgh auth login --webClone, push, PRs, issues.
Vercelvercel loginDeploy and project inspection.
Supabasesupabase loginMigrations and project management.
Niania auth loginIndexed repo/docs/context search.
Exalocal EXA_API_KEYKeep in local Codex config only.
Repowise Gemini.repowise/.envLocal ignored project file. Never print it.
Bitwarden is not default. A password manager avoids Slack-pasting, but cannot stop a trusted intern or local agent from copying a raw key after access is granted. Use per-user accounts, scoped/staging keys, ignored local env files, logs, revocation, and rotation.

05 · Daily Workflow

  1. Load /caveman ultra.
  2. Load $edward-rules.
  3. Read the project PROJECT.md, recent decision notes, and AGENTS.local.md if present.
  4. Ask Codex first. Understand the options and blast radius before escalating.
  5. Before PR/end of meaningful work, run decision capture and update project notes if context changed.

Default answer

Did you ask Codex? What did Codex say?

06 · GStack, Repowise, Escalation

GStack

git clone --single-branch --depth 1 https://github.com/giaphutran12/codex-gstack.git ~/.gstack/repos/gstack
cd ~/.gstack/repos/gstack
./setup --host codex

Use gstack investigate before saying stuck. Use gstack ship for PR/review/shipping flow.

Repowise

./scripts/repowise-update.sh /path/to/project --provider gemini

Repowise is for repo/code orientation, not Edward Rules. It helps reduce context waste before agents make changes.
