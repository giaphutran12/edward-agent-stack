Paste This Into Codex

Install Edward's agent stack on this fresh MacBook. Clone https://github.com/giaphutran12/edward-agent-stack to ~/edward-agent-stack, read AGENTS.md, then run ./scripts/bootstrap-macos.sh, ./scripts/install.sh, ./scripts/verify.sh, and ./scripts/auth-doctor.sh. Use /caveman ultra. Do not inspect or print real env/secret files. If a tool needs login, API key, license acceptance, or GUI first-run, stop and tell me exactly what is missing.

Secret Model

Use per-user accounts, staging-only or low-quota keys, local ignored env files, logs, revocation, and scheduled rotation. Password managers solve distribution hygiene; they do not solve insider key abuse.
