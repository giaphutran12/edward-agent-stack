What This Gives The Intern

  • A one-command setup path Codex can run and verify.
  • Edward's default engineering rules without private personal context.
  • A place to record project facts and decisions so Edward is not asked the same thing twice.

1. Paste This Into Codex

Install Edward's agent stack on this fresh MacBook. Clone https://github.com/giaphutran12/edward-agent-stack to ~/edward-agent-stack, read AGENTS.md, then run ./scripts/bootstrap-macos.sh, ./scripts/install.sh, ./scripts/verify.sh, and ./scripts/auth-doctor.sh. Use /caveman ultra. Do not inspect or print local real env/secret files. If a tool needs login, API key, license acceptance, or GUI first-run, stop and tell me exactly what is missing.

5. Ask Edward Only When Needed

  • Tradeoff still unclear after Codex, docs, and tests.

Secret Rule

No real secrets should be committed. Local ignored env files may exist for execution, but agents should not inspect or print them. For interns, prefer per-user accounts, staging/low-scope keys, logs, revocation, and rotation.
